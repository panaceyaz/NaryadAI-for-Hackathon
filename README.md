# 🛡️ NaryadAI (Наряд-Допуск AI)

> **Интеллектуальная система управления и ИИ-контроля техники безопасности и нарядов-допусков на производстве.**

NaryadAI автоматизирует полный цикл работы с нарядами-допусками — от выдачи таска мастеру до интеллектуальной проверки выполненных работ с помощью компьютерного зрения и нейросетей.

---

## 🚀 Основные возможности

* 📋 **Цифровой наряд-допуск** — быстрый запуск и согласование опасных работ без бумажной волокиты.
* 🪟 **Интерактивная Kanban-доска** — наглядный отслеживатель статусов задач в реальном времени.
* 🤖 **ИИ-Контроль (Computer Vision)** — автоматический анализ фотофиксации работ на предмет соблюдения ТБ и СИЗ (каски, перчатки, ограждения).
* 📱 **Мобильный адаптив** — удобный интерфейс для рабочих и бригадиров прямо на объекте.

---

## 🛠️ Стек технологий

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Backend / AI:** Python, Flask / FastAPI, OpenCV / PyTorch
* **Database:** SQLite / PostgreSQL
